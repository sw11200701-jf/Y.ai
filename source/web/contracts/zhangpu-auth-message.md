## Public authentication routes

GET /auth/status => {initialized,authentication_required:true,development_http:boolean}; GET /auth/csrf => {csrf_token} plus short-lived HttpOnly preauth cookie. The CSRF token is returned only over same-origin JSON, keep in memory, never localStorage/logs. All POST/PUT/PATCH/DELETE require `X-CSRF-Token` plus allowed Origin (browser) or absent Origin with valid CSRF+cookie (CLI); mismatched/missingOrigin from browser rejected using Sec-Fetch-Site. Allowed origins exact env FINANCE_ALLOWED_WEB_ORIGINS, candidate default http://127.0.0.1:3201 and API8200. No wildcard CORS or credential wildcard.

POST /auth/setup `{username,password,display_name?}` => first installationadmin+newsession, only once and onlyloopback/administrator startup context; password chosen locally in UI, never prefilled. Requires preauthCSRF; setup transaction serialized, existing unownedlegacydata assigned explicitly to first installationadmin in preserved historicalspace (demo-enterprise/demo-workspace), no deletion/shared-by-default. Setupstatus exposes no secrets.

POST /auth/login `{username,password}` => {user,csrf_token,expires_at}; generic invalid credentials; rotates/revokes prior cookie session to prevent fixation. Persistent server-side session stores hashed opaque token only, HttpOnly/SameSite=Lax/path=/ cookie, Secure bydefault; explicit FINANCE_DEVELOPMENT_HTTP=true for localhostHTTPcandidate. Absolute expiry8h, idle30min, logout/admin/password/accountdisable revoke. GET /auth/me => {user,csrf_token,expires_at,workspace}; POST /auth/logout revokes/deletescookie, clears frontend query/result caches. GETcsrf when loggedin returns sessionCSRF; preauth token is not an authenticatedsession. Password hashing maturelibrary; no credentials printed/committed. Login/setup throttled by peer+normalizedaccount, persistent failure windows; user-visible error never distinguishes unknown/disabled accounts.

All /api/v1 business routes, /openapi.json and /docs require session except auth/status/csrf/setup/login and minimal /healthz. No anonymous demo-context fallback; arbitrary tenant/owner headers ignored/rejected. Sensitive responses Cache-Control:no-store, Vary:Cookie. Non-administrators cannot select tenant/workspace/roles in businesspayloads.

If message supplied: textrequires nonblanktext/noattachments; imagerequires1..8imageattachments/nootherMIME; audiorequires1audioattachment; filerequires1..8documentattachments; mixedrequiresnonblanktext AND1..8attachments (at leastone ofimage/audio/document).
